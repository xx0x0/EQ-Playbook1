# 海外华人档 · 其他场景怎么走

> 这一档只单独写了 `dating.md`，因为**约会是差异最大、最容易踩雷的场景**。
> 其他场景不重复造轮子，用下面的路由。

---

## 路由

| 场景 | 用哪个 | 差异 |
|---|---|---|
| **约会 / 亲密关系** | **`overseas-chinese/dating.md`** | 单独写了 |
| 日常人际 | `uk/daily.md` | 基本通用；**英式潜台词那一节仍然适用**（他们在英语环境长大） |
| 职场对上级 | `uk/work-upward.md` | **职场比约会西化得彻底**，直接用英式 |
| 职场对下级 | `uk/work-downward.md` | 同上 |

---

## 为什么职场可以直接用英式，约会不行

**职场行为是在职场里习得的**——如果他在英美体系里工作，他的汇报方式、
反馈方式、拒绝方式都是从那个体系学来的，和本地人差别很小。

**约会行为是在家里习得的**——关于钱、家庭、承诺、面子的期待，
来自父母和成长环境，**不会因为在哪工作而改变。**

所以：**看这个人在哪里学的这套行为，就用哪一档。**

---

## 唯一需要加在日常场景上的一条

`uk/daily.md` 里那套 banter（互怼）**可以用，但强度调低一档**，
且**有第三个人在场时不要开他的玩笑**——面子层在群体场合更容易被激活。

其余照 `uk/` 走。
