# EQ Playbook · 高情商沟通手册（中英对照）

A bilingual playbook for high-EQ communication — everyday, dating, and workplace.
每一条话术都是 **English + 中文** 对照，兼作英语学习材料。默认 **British English**。

---

## 为什么是中英对照

目的是两个，不是一个：

1. **高情商** — 学会在真实场景里说对的话
2. **英语** — 每条话术都是母语者真的会说的句子，用的时候顺便在学

所以格式是固定的四行：

```
EN｜  "I had a really good time. Genuinely."
中｜  我今天真的很开心。真心的。
用在｜ 约会结束、道别时
为什么｜英国人客套太多，所以专门标注「这句不是客套」时，信号强度会突然拉满
```

**缺「为什么」的话术是学不会的**——你只能背，不能迁移。

## 为什么分三档

**同一个行为在三种文化里意味着完全不同的东西。** 举三个：

| | 英国 | 大陆 |
|---|---|---|
| 他提 AA | **中性，不代表不喜欢** | 负面信号 |
| 互怼（banter） | **能怼＝关系近** | 对刚认识的人有风险 |
| 确立关系 | 没有告白，靠对话或自然过渡 | 有明确的「在一起」动作 |

用错档的代价不是「不好笑」，是**把喜欢读成不喜欢**。

**第三档（海外华人）最难，也最常见。** 它不是「中西的中间值」，
而是**在不同议题上分别启用不同的一套**：约会节奏完全西化，
但钱、家庭、面子上完全中式——而且他自己往往没意识到。

## 四条核心原则（详见 `principles/00-core.md`）

**1. 聊天是「有来有往」，不是单方面接话**
五个动作：回球 / 推动 / 捡闪光点 / **问动机** / 让对方被看懂。
最值钱的是第四条——大部分人停在「是什么」，会聊天的人往下走到「**为什么会是这个**」。
最狠的是第五条——**让对方觉得被看懂，比让他觉得被喜欢更难被替代。**

**2. 主动给温度，不主动降门槛**
信号（兴趣、回应、温度）全给；代价（安排、买单、迁就）不给。
这两件事被大部分「不要主动」的建议混成了一件，所以才有「一克制就没火花，一放松就白给」的死结。

**3. 拒绝要短，收尾不评价**
理由是给对方的反驳接口；评价在被拒的人耳朵里是打分。

**4. 能力优先于结果**
一次互动的成败次要，练到的可迁移能力主要。所以试错本身就是产出。

## 加素材

把视频笔记、看到的话、自己的观察，**原样贴进对话就行**，不用整理。
我会存进 `principles/INBOX.md`，判断它是原则还是话术，然后消化进对应位置。

贴的时候如果方便，顺手标两件事：
1. **来源**（视频 / 书 / 朋友 / 自己观察）
2. **你信到什么程度**（完全认同 / 大方向对但有保留 / 先存着）

第 2 条决定它是变成**原则**（会覆盖书里的说法）还是只作为**参考**存着。
