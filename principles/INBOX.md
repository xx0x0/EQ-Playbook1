# 素材收件箱

> 用户随时丢进来的原始素材（视频笔记、截图文字、别人说的话、自己的观察）。
> 我会定期把它们消化成 `00-core.md` 的原则，或者补进对应的 playbook。
>
> **丢进来的时候不用整理格式，原样贴就行。**

---

## 处理流程

1. 用户贴一段 → 我原样存进这里，标日期和来源
2. 判断它是**原则**（价值观层）还是**话术**（执行层）
   - 原则 → 提炼进 `principles/00-core.md`，附「拆成可执行动作」
   - 话术 → 补进对应 `playbooks/*.md`，补上英文版和「为什么」
3. **和已有的覆盖规则对齐**（见下，这一步不能省）
4. 与已有原则冲突时 → **不删旧的**，两条都留，标注冲突点，问用户以哪条为准

## 工具分工

| | 用哪个 |
|---|---|
| **读**：大量原文、OCR、探索式问答 | 外部阅读工具（NotebookLM 等） |
| **判断**：这个具体的人怎么办、话术怎么说 | 本手册 |

**分工的那道缝：书不在这边，就引证不到原文。**
所以从外部工具倒结论过来时，**连原文一起倒**，用下面这个三行模板：

```
书名 p123
原文：「……逐字复制……」
我的判断：完全认同 / 大方向对但有保留 / 先存着
```

不用整理格式。第三行决定它变成**原则**（会覆盖书里的说法）还是只作为**参考**存着。

---

## ⚠️ 外部结论必须先对齐再采纳

外部阅读工具给的是**通用读者**的结论。它不知道下面这些，所以不能直接采信：

| 已确立的覆盖规则 | 出处 |
|---|---|
| 现代男生不给信号就算了 → **主动给温度，不主动降门槛** | `00-core.md` 原则 2（用户 8 个对象的实证） |
| 约会要 AA 的**不在正常交往范畴** | 用户标准，2026-08-18 |
| 同一句话对英国人 / 大陆人 / 海外华人意思不同 | `playbooks/00-culture-map.md` |
| 拒绝要短，收尾不评价 | `00-core.md` 原则 3 |
| 能力优先于结果（练英语 + 高情商） | `00-core.md` 原则 4 |

**同一本书的同一段话，对用户的意义和对通用读者的意义不一样。**
外部工具给的是后者，本手册负责翻译成前者。

## 我需要你在贴素材时顺手标的两件事（能标就标，不标我也会问）

1. **来源** — 视频/书/朋友说的/自己观察到的
2. **你信到什么程度** — 「完全认同」/「大方向对但有保留」/「先存着，还没想清楚」

第 2 条最重要。**完全认同的会变成原则（覆盖书里的说法）；有保留的只会作为参考存着。**
